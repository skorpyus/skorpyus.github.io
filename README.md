# skorpyus.github.io

Sitio personal de Salvador Spano, publicado con GitHub Pages en https://skorpyus.github.io

- `index.html`: perfil y carrera profesional (sobre mí, resultados, trayectoria, proyecto, aptitudes, contacto).
- `consultoria.html`: servicios de consultoría en mejora y eficiencia de procesos con orientación a soluciones tecnológicas.
- `css/site.css` y `js/site.js`: estilos y comportamiento compartidos (menú móvil, sección activa, modo oscuro automático).

Es HTML estático sin build; para verlo localmente alcanza con abrir `index.html` en el navegador.
